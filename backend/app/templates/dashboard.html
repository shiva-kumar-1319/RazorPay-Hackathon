📐 Net Expected Value Decision Rule
Net EV(a) = P(Success | x, a) × Amount
          - C_rail(a)
          - F_customer(a)
P(Success | x, a) — Calibrated recovery probability from CalibratedClassifierCV with Isotonic regression over GradientBoosting
Amount — Transaction value in INR
C_rail(a) — Gateway/network execution cost (RETRY: ₹0.50, UPI switch: ₹1.00, Payment Link: ₹1.50)
F_customer(a) — Friction penalty: intrusive outreach prevents checkout abandonment & brand fatigue
AGENT SELECTION RULE
a* = argmaxa ∈ Actions Net EV(a)
If all Net EV(a) < 0 → agent selects STOP_RECOVERY to prevent value destruction

⚙️ Fail-Safe Architecture — Deterministic Guardrails
🔒
Zero LLM Dependency for Safety
Core hard-stop decisions and double-recovery guards are enforced deterministically in Python/SQL. If an LLM is offline, the agent functions autonomously with 100% precision.
🔄
Optimistic Concurrency — Version Guard
Transactions enforce version increments (Transaction.version += 1) to prevent concurrent race conditions and double-charging.
🎫
Idempotent Caching — SHA-Keyed
Actions submitted with identical idempotency keys return cached responses without executing secondary financial attempts. Prevents double-billing.
🏢
Tenant Isolation — merchant_id Validation
Execution requests verify merchant_id ownership on every request, preventing cross-tenant data leakage or unauthorized recovery actions.
🔐 SHA-256 Cryptographic Audit Chain — Tamper-Evident Ledger
🔗 Hash Chain Construction
event_hash = SHA256(
  step_number | timestamp | stage
  | actor | action | details_json
  | previous_hash ← Chain Link
)
Each audit event is cryptographically linked to the previous one. Modifying any event breaks the entire chain — providing tamper detection.
